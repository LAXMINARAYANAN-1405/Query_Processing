# Query Processing Labs

This repository contains 40 Python lab exercises for query processing and data analysis. Each lab folder includes its Python script and any sample data or generated output files used by the exercise.

## Requirements

- Python 3
- pandas
- NumPy
- Matplotlib

Install the required packages with:

```bash
python -m pip install pandas numpy matplotlib
```

## Lab folders

- Labs 1–5 are in `lab-1` through `lab-5`.
- Labs 6–40 are in `lab6` through `lab40`.

## Running a lab

Run the script from its folder so it can find any accompanying data files. For example:

```bash
cd lab-1
python lab1.py
```

Replace `lab-1` and `lab1.py` with the folder and script for the lab you want to run.

## Outputs

Depending on the exercise, results are printed to the terminal or saved as a text file or graph in the lab folder. Existing generated outputs are included alongside their lab scripts.
